# ClimaCanarias

ClimaCanarias es una plataforma meteorológica de alta precisión, diseñada específicamente para capturar la complejidad climática de las Islas Canarias. Ofrece una visión unificada, minimalista y en tiempo real del estado atmosférico regional.

## Visión General

La aplicación integra de forma inteligente fuentes meteorológicas globales (AEMET, OpenWeatherMap, Open-Meteo) para proporcionar previsiones contextualizadas. Reconoce patrones climáticos específicos del ecosistema canario, como la calima y la dinámica de los vientos alisios, entregando alertas críticas y tendencias de alta resolución en una interfaz optimizada para lectura rápida.

## Capacidades Principales

*   **Integración de Consenso**: Procesamiento de datos de múltiples fuentes para asegurar la máxima fiabilidad en la previsión regional.
*   **Detección de Fenómenos Locales**: Análisis automatizado de intrusiones de polvo (calima) y regimenes de alisios.
*   **Inteligencia de Alertas**: Sistema de visualización clara para avisos de Protección Civil.
*   **Experiencia Sincronizada**: Gestión segura de preferencias de usuario mediante Firebase con autenticación de Google.
*   **Diseño Consciente**: Interfaz minimalista con modo AMOLED automático, priorizando la legibilidad y la eficiencia energética.

## Stack Tecnológico

La arquitectura de ClimaCanarias apuesta por la modernidad y la escalabilidad:

*   **Motor Frontend**: React 18 / TypeScript / Vite.
*   **Sistema de Diseño**: Tailwind CSS con transiciones de Motion.
*   **Backend & Seguridad**: Firebase Authentication y Firestore.
